# Arcade Stage Fighter

Jogo de luta e sobrevivência em fases feito com Python e Pygame.

## Requisitos

- Python 3.9 ou superior
- Pygame

## Instalação e execução

```bash
pip install -r requirements.txt
python arcade_stage_fighter.py
```

## Controles

- **A / D** ou **← / →**: mover
- **W** ou **↑**: pular
- **Espaço** ou **J**: atacar
- **1–4**: escolher personagem no menu
- **Enter**: iniciar / voltar ao menu
